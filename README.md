# cv3-assignment

라방바 데이터랩의 라이브방송/홈쇼핑 랭킹 데이터를 가져와 보여주는 웹페이지입니다.

## 실행 환경

- OS: Windows
- Node.js: v24.12.0 (개발 환경 기준, **Node.js 18 이상**이면 동작합니다)

## 실행 방법

### 1. 저장소 클론 / 압축 해제

```bash
git clone <저장소 URL>
cd cv3-assignment
```

(zip으로 받았다면 압축을 풀고 해당 폴더로 이동합니다.)

### 2. 서버 환경변수 설정

`server/.env` 파일을 새로 만들고 아래 항목을 채워 넣습니다.

```
CV3_TEST_ID=본인의 테스트 계정 이메일로 채우세요
CV3_TEST_PW=본인의 테스트 계정 비밀번호로 채우세요
PORT=4000
```

- `CV3_TEST_ID` / `CV3_TEST_PW`: 라방바 데이터랩 로그인에 사용할 본인의 테스트 계정 정보입니다. 실제 값은 이 README나 저장소에 절대 커밋하지 말고 로컬 `server/.env`에만 넣으세요 (`.gitignore`에 이미 포함되어 있습니다).
- `PORT`: 백엔드 서버 포트. 기본값은 `4000`입니다.

### 3. 백엔드(server) 설치 및 실행

```bash
cd server
npm install
npm run dev
```

정상적으로 실행되면 콘솔에 로그인 성공, 카테고리 로드, 폴링 성공 로그가 순서대로 출력됩니다. 이 로그들을 먼저 확인한 뒤 프론트엔드를 실행하는 것을 권장합니다.

### 4. 프론트엔드(client) 설치 및 실행

새 터미널을 열고:

```bash
cd client
npm install
npm run dev
```

### 5. 브라우저 접속

백엔드와 프론트엔드가 모두 실행 중인 상태에서 브라우저로 아래 주소에 접속합니다.

```
http://localhost:5173
```

화면의 조회수/판매량/매출액 등은 실제 서비스 값을 약 8초 간격으로 폴링해 자동 갱신되므로, 새로고침 없이도 숫자가 주기적으로 바뀌는 것이 정상 동작입니다.
